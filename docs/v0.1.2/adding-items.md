## Weapon

Set `"Type": "weapon"`.

| Field | Description | Type |
|---|---|---|
| `Damage` | Weapon damage | 0–255 |
| `ReloadTime` | Reload time in ticks (1 s = 20 ticks) | 0–255 |
| `Spread` | Spread angle | number |
| `Pushback` | Pushback force | 0–1 |
| `AnimationSpeed` | Animation speed | 0.00+ |
| `PowerUsage` | Suit power used per shot | 0–255 |
| `ShotSound` | Shot sound | sound name |
| `Projectile` | Projectile file name from the `Projectiles` folder, see [Projectiles](./projectiles) | name |
