# Supported file types

| Kind | Formats | Notes |
|---|---|---|
| Textures | `png`, `jpg` | Block textures are 32 × 32 pixels (see `BlockSize`). |
| Sounds | `ogg` (recommended), `wav` | |
| Models | `obj` | |
| Archives | `zip` (recommended), `rar` | `rar` support may be removed in later versions. |
