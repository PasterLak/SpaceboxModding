Spacebox content is data. Blocks, items, recipes and starting items are described in JSON files with PNG textures and OGG/WAV sounds, so you can mod the game without writing code.

In this version a mod is a **GameSet**: a folder in `GameSets/` that holds all blocks, items and recipes of a world. The game ships with the `Default` GameSet; copy it to start your own.
